# Current contract access assignment

The [WP01.01 Design profile](https://github.com/ArcForges/ArcForges-Design/blob/94b3ec43389d8ec6f8cd3ad277daf0eac5e9259e/docs/assurance/wp01-01-contract-access-policy.md) governs `eng/policy/contract-access.json`.

The current assignment is public Apache-2.0 for both Hello messages and the Hello service. All 34 declared source types in 18 distribution files belong to their seven public packages. This includes generated nested clients/builders/reflection helpers and the authored `ContractFixtures` accessor. The TypeScript factory and exports have no extra declared types; the empty generated Kotlin file is inventoried too. Private language visibility of a generator helper does not turn it into a private wire protocol. No current type needs public/internal reclassification, and no retired C# DTO scaffold is recreated.

After `python eng/contracts.py restore`, run:

```text
node eng/check_contract_access.mjs
node --test tests/tooling/contract_access.test.mjs
```

The gate compiles all current proto with the pinned Grpc.Tools protoc and reads its descriptor through the locked protobuf-es runtime. Every message, nested message, enum and service must match the explicit inventory. File imports and type/RPC dependencies are checked transitively; unused private imports are rejected too. Internal-to-public references are allowed. Real temporary proto fixtures test both directions and nested assignment omissions. Extension declarations require a future explicit assignment profile before admission.

Source declarations use a bounded lexical inventory for the current generated languages, backed by exact file hashes and the existing regeneration check. It is not a general compiler or a whole-program analyzer. All generated files, authored distribution sources and 24 current package graph inputs are closed and hash-bound; changes require reviewed inventory updates. Unknown source or package graph inputs fail. Existing licence, provenance, format, wire and isolated archive consumer gates remain mandatory.

`build` and therefore `pack` run the access gate. CI retains `artifacts/evidence/contract-access.json` and runs the real-proto failure tests before packing. Existing package versions, fields, generated bytes, consumer pins and the native-gRPC Hello compatibility artifact remain unchanged. Full production public/internal/operator/local/AI schemas and generated packages remain WP03, under the complete wire registry and its annexes; this small current assignment does not close those obligations.
